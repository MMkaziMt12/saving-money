# **App Name**: Family Fund Tracker

## Core Features:

- Contribution Dashboard: Dashboard for displaying contributions, pending amounts, and total family savings.
- Emergency Request Form: Form to request emergency funds with a description of the emergency.
- Secure User Management: User authentication and approval workflow with admin privileges.
- Admin Panel: Admin panel for managing user approvals, contributions, and emergency requests.
- AI-Powered Notifications: Generate notification messages with an AI tool, suggesting the best wording for pending contribution reminders or emergency fund request updates.

## Style Guidelines:

- Primary color: A calming blue (#3498db) to inspire trust.
- Secondary color: A soft gray (#ecf0f1) for backgrounds and less important elements.
- Accent: Green (#2ecc71) for positive actions like successful contributions or approved requests.
- Clean and modern font for readability across all devices.
- Simple, consistent icons for navigation and actions.
- Responsive layout adapting to different screen sizes.
